Kecepatan Putar:
📌 Rangkuman Pemahaman Animasi Firewall:
1. Packet Inspection (Inspeksi Paket): Firewall membaca IP asal, IP tujuan, protokol (TCP/UDP), dan nomor port sebelum mengambil keputusan.
2. ALLOW HTTP (80) & HTTPS (443): Lalu lintas web aman diizinkan diteruskan ke server web sekolah.
3. BLOCK / DROP Telnet (23): Port usang tanpa enkripsi dicegat di gerbang dan dibuang agar terhindar dari sniffing.
4. BLOCK DDoS Flood (ICMP): Lonjakan trafik abnormal otomatis dijatuhkan (*dropped*) agar server tidak kehabisan memori.
5. Prinsip Default Deny: Port yang tidak terdaftar secara resmi otomatis ditolak oleh firewall.
