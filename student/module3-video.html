Rangkuman Video:
1. Packet Inspection: Firewall membaca IP asal, IP tujuan, protokol, dan port sebelum mengambil keputusan.
2. ALLOW HTTP 80 & HTTPS 443: Lalu lintas web aman diteruskan ke server web sekolah.
3. BLOCK Telnet 23: Port rentan tanpa enkripsi dicegat dan dibuang agar terhindar dari peretasan.
4. BLOCK DDoS Flood: Lonjakan paket ICMP abnormal otomatis di-drop agar server tidak mati.
