📌 Poin Inti Pembahasan Video:
🦠
1. Virus Komputer

Membutuhkan file induk (host) dan eksekusi aktif pengguna untuk menginfeksi komputer.

🐛
2. Worm Jaringan

Menyebar mandiri melalui celah port jaringan terbuka tanpa memerlukan bantuan interaksi pengguna.

🎣
3. Rekayasa Phishing

Menyamar sebagai pihak tepercaya untuk memancing korban menyerahkan kredensial akun rahasia.

🌊
4. Serangan DDoS

Banjir lalu lintas data masif dari jaringan botnet untuk melumpuhkan server target hingga down.
