A. Pengertian dan Fungsi Utama Firewall

Firewall adalah sistem keamanan jaringan yang bertindak sebagai tembok pembatas terisolasi antara jaringan internal sekolah (yang tepercaya) dengan jaringan eksternal seperti internet (yang tidak tepercaya). Seluruh lalu lintas data yang masuk (*inbound*) maupun keluar (*outbound*) harus melewati pos pemeriksaan firewall.

Tiga fungsi esensial firewall pada sistem administrasi jaringan:

  • Menyaring Lalu Lintas Paket (Packet Filtering): Menganalisis parameter header data untuk memastikan hanya paket resmi yang diizinkan lewat.
  • Memblokir Port Berisiko (Port Blocking): Menutup akses port layanan yang tidak digunakan atau rentan eksploitasi peretas (misal: port Telnet 23).
  • Mencegah Serangan Banjir (Denial of Service): Mendeteksi lonjakan volume permintaan abnormal dan secara otomatis menjatuhkan (*drop*) paket penyerang.

B. Mekanisme Penyaringan Paket Data (Packet Filtering)

Pada tingkat penyaringan paket (*Packet Filtering Firewall*), firewall memeriksa informasi yang terdapat pada layer 3 (*Network*) dan layer 4 (*Transport*) model OSI:

  1. IP Asal (Source IP): Alamat komputer pengirim paket data.
  2. IP Tujuan (Destination IP): Alamat komputer atau server yang dituju.
  3. Protokol Komunikasi: Protokol transport yang digunakan (TCP, UDP, atau ICMP).
  4. Nomor Port Layanan:
    • Port 80 (HTTP): Layanan browsing website tanpa enkripsi standar.
    • Port 443 (HTTPS): Layanan browsing website aman berenkripsi SSL/TLS.
    • Port 23 (Telnet): Layanan remote login jadul tanpa enkripsi teks (sangat berbahaya).
    • Port 22 (SSH): Layanan remote login terenkripsi aman sebagai pengganti Telnet.
Prinsip Emas: "Default Deny / Default Block"
Dalam standar industri keamanan jaringan, aturan terbaik adalah Default Deny: secara otomatis tolak (Block) seluruh paket data tak dikenal, dan hanya buat aturan Allow untuk port yang secara tegas dibutuhkan (seperti port 80 dan 443).

C. Dua Aksi Kebijakan Aturan Firewall (Rule Actions)

✓

ALLOW (Izinkan)

Lalu Lintas Diterima

Firewall mengizinkan paket data melewati antarmuka jaringan dan diteruskan ke server target. Diterapkan untuk lalu lintas terverifikasi yang aman, seperti browsing web HTTPS port 443.

✕

BLOCK / DROP (Tolak)

Lalu Lintas Ditolak

Firewall menghentikan dan membuang paket data di gerbang perimeter tanpa meneruskannya ke server. Diterapkan untuk port berbahaya (Telnet port 23) atau banjir paket serangan DDoS.
