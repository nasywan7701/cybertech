Anatomi Antivirus & Endpoint Detection

Membedah 2 pilar teknologi antivirus dalam melacak malware sebelum merusak sistem operasi.

DUA METODE DETEKSI UTAMA

1. Deteksi Berbasis Signature (Sidik Jari)

Membandingkan nilai hash unik (MD5/SHA-256) file target dengan jutaan database malware dunia yang sudah dikenal.

Sangat Cepat & Akurat untuk Virus Lama • Butuh Update Rutin

2. Deteksi Heuristik & Behavioral (Perilaku)

Menganalisis tingkah laku mencurigakan secara cerdas, seperti file yang mencoba memodifikasi registri sistem atau menyuntikkan proses DLL secara diam-diam.

Efektif Melawan Serangan Hari-Nol (Zero-Day Attacks)

Alur Penanganan Malware di Komputer Siswa:

1. File Diunduh

Browser / Flashdisk memasukkan file ke harddisk.

2. Pemindaian Residen

Antivirus mencegat sebelum file dieksekusi.

3. Karantina (Vault)

File diisolasi di folder terkunci tanpa izin eksekusi.

4. Pembersihan / Hapus

Kode virus dipotong atau file dimusnahkan permanen.

Matriks Penyaringan Paket Firewall

Bagaimana firewall memeriksa identitas paket data berdasarkan Port, IP, dan Protokol.

ANATOMI KEPUTUSAN FIREWALL

Setiap paket yang lewat melalui interface router diperiksa terhadap daftar aturan (*Access Control List / ACL*):

Tindakan: ALLOW (ACCEPT)

Paket lolos verifikasi keamanan dan diteruskan ke server aplikasi di dalam jaringan laboratorium.

Contoh: Port 443 (HTTPS) web sekolah

Tindakan: DROP / BLOCK

Paket dibuang diam-diam di gerbang firewall tanpa memberi tahu pengirim, menghemat bandwidth dari serangan flood.

Contoh: Port 23 (Telnet tak terenkripsi)

Tindakan: REJECT

Paket ditolak dan firewall mengirim balasan sinyal ICMP Port Unreachable kepada pengirim.

Contoh: Komputer klien tanpa izin akses

Matriks Port Jaringan Penting untuk Administrasi Server:

Protokol / Layanan Nomor Port Tingkat Keamanan Rekomendasi Kebijakan Firewall
HTTPS (Web Aman) 443 / TCP Tinggi (TLS) ALLOW untuk seluruh publik
SSH (Remote Server Aman) 22 / TCP Tinggi (Kriptografi) ALLOW hanya dari IP Guru / Admin
Telnet (Remote Jadul) 23 / TCP Rentan (Plaintext) DROP / BLOCK secara permanen
SMB / RPC (File Sharing) 445 / TCP Celah Ransomware BLOCK dari akses internet luar

Terowongan Enkripsi VPN (Virtual Private Network)

Perbandingan transmisi data saat menggunakan Wi-Fi Publik tanpa VPN vs dengan VPN.

SIMULASI PAKET SNIFFING DI WI-FI PUBLIK

Laptop / HP Siswa

Mengirim request data login ke server sekolah:
POST /login HTTP/1.1
User: siswa_tkj
Pass: rahasia123

Yang Terbaca Hacker di Wi-Fi Publik:

[PLAINTEXT BOCOR!]
Username: siswa_tkj
Password: rahasia123
Bahaya: Password akun langsung terbaca jelas tanpa perlindungan enkripsi!

Cara Kerja Terowongan VPN (Tunneling):

VPN membungkus seluruh paket data IP dalam amplop enkripsi yang hanya dapat dibuka oleh server VPN sekolah. Pihak ketiga seperti penyedia Wi-Fi kafe atau penyerang *Man-in-the-Middle* hanya akan melihat aliran karakter acak (ciphertext) tak bermakna yang mustahil didekripsi dalam waktu manusiawi.

Ekosistem Autentikasi Multifaktor (2FA / MFA)

Mencegah pembobolan akun bahkan ketika password pengguna telah bocor di internet.

3 PILAR IDENTITAS KEAMANAN (MFA FACTORS)

1. Something You Know

Informasi rahasia yang hanya diingat oleh pemilik akun di otaknya.

Contoh: Password, Kode PIN, Jawaban Pertanyaan Rahasia.

2. Something You Have

Benda fisik yang dipegang dan dimiliki oleh pengguna secara nyata.

Contoh: Smartphone dengan Aplikasi OTP (Google Auth), Hardware USB Key (YubiKey), SMS Token.

3. Something You Are

Karakteristik fisik unik biologis dari tubuh manusia itu sendiri.

Contoh: Sidik Jari (Fingerprint), Face ID, Pemindai Retina Mata.

Fakta Nyata Keamanan Siber (Sumber: CISA & Microsoft Security):

• 99.9% Serangan Pembobolan Akun otomatis gagal jika akun mengaktifkan 2FA.
• Walaupun peretas membeli daftar bocoran password di Dark Web, mereka tetap tidak dapat login karena tidak memegang smartphone siswa untuk menerima kode 6-digit OTP yang berganti setiap 30 detik!
